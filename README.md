# Fog Backup Tools

Fog Backup Tools lets Game Masters create and restore complete Fog of War snapshots for individual scenes in Foundry VTT.

## Features

- Export the current Fog of War state of a scene
- Import a previously saved Fog snapshot
- Restores fog for the GM and all connected players
- Works with Shared Fog
- Easy access through dedicated scene buttons

## Installation

Copy the module to:

`Data/modules/fog-backup-tools`

Enable the module in your world and restart Foundry VTT if required.
